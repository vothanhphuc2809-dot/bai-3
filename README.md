## BÀI THỰC HÀNH 01 – NODE.JS

### 1. Tạo tập tin bai01.js
Tạo file `bai01.js` trong thư mục bài thực hành để viết chương trình quản lý danh sách sinh viên.

### 2. Nhập đoạn code trong file bai01.js
- Khai báo danh sách gồm 5 sinh viên.
- Sử dụng `class` và `constructor` để tạo thông tin sinh viên.
- Sử dụng `arrow function` để lọc sinh viên có điểm từ 5 trở lên.
- Sử dụng `console.log()` để hiển thị danh sách sinh viên đạt yêu cầu.
